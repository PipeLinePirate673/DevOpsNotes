# Files and Directories — Command Cheat Sheet


| Command    | Example                           | Short Description                             |
| ---------- | --------------------------------- | --------------------------------------------- |
| `ls`       | `ls`                              | List files and directories.                   |
| `ls -l`    | `ls -l`                           | List files with detailed information.         |
| `ls -a`    | `ls -a`                           | Show hidden files and directories.            |
| `ls -la`   | `ls -la`                          | Show all files with detailed information.     |
| `mkdir`    | `mkdir projects`                  | Create a directory.                           |
| `mkdir -p` | `mkdir -p projects/linux/scripts` | Create nested directories.                    |
| `touch`    | `touch notes.txt`                 | Create an empty file.                         |
| `cp`       | `cp notes.txt backup/`            | Copy a file.                                  |
| `cp -r`    | `cp -r files/ backup/`            | Copy a directory and its contents.            |
| `mv`       | `mv notes.txt Documents/`         | Move a file or directory.                     |
| `mv`       | `mv old.txt new.txt`              | Rename a file or directory.                   |
| `rm`       | `rm notes.txt`                    | Remove a file.                                |
| `rm -r`    | `rm -r old-files/`                | Remove a directory and its contents.          |
| `rmdir`    | `rmdir empty/`                    | Remove an empty directory.                    |
| `file`     | `file notes.txt`                  | Show the type of a file.                      |
| `stat`     | `stat notes.txt`                  | Show detailed file information.               |
| `find`     | `find . -name "*.txt"`            | Search for files and directories.             |
| `tree`     | `tree`                            | Display a directory structure.                |
| `tree -a`  | `tree -a`                         | Display the structure including hidden files. |
| `du -h`    | `du -h Documents/`                | Show directory and file sizes.                |
| `du -sh`   | `du -sh Documents/`               | Show the total size of a directory.           |
| `df -h`    | `df -h`                           | Show filesystem disk usage.                   |
