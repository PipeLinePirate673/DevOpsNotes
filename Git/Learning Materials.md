# Learning Materials


### 1. GitHub — Learning Resources

Official GitHub learning resources covering GitHub workflows, Git, online courses, training, and community resources.

[GitHub — Git and GitHub Learning Resources](https://docs.github.com/en/get-started/start-your-journey/git-and-github-learning-resources)

### 2. Git — Official Website

The official Git website.

Useful resources include:

- Git documentation
- Git command reference
- Pro Git book
- Git installation
- Git tutorials

[Git — Official Website](https://git-scm.com/)

---

### 3. Git & GitHub Crash Course

A video crash course covering the fundamentals of Git and GitHub.

[Git & GitHub Crash Course 2025 — YouTube](https://www.youtube.com/watch?v=vA5TTz6BXhY)

---

### 4. Learn Git Branching

An interactive browser-based environment for learning and practicing Git concepts, especially branches and Git history.

[Learn Git Branching](https://learngitbranching.js.org/)

---

## Recommended Order

1. **Git & GitHub Crash Course** — get a basic overview.
2. **Git — Official Website** — learn the fundamentals and use the documentation as a reference.
3. **Learn Git Branching** — practice branches and Git operations interactively.
4. **GitHub Learning Resources** — learn how Git and GitHub fit into real development workflows.
