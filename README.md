## 📚 How I use these notes

For every topic I learn, I want to write down things that are actually useful to me.

Usually this means:

- what something is
- how it works
- important commands
- examples
- configuration
- problems I had
- how I fixed them
- things I should remember
- things I still don't fully understand

I will try to explain things in my own words instead of just copying documentation.

---

## 🧪 Learning by doing

I want to learn mostly by actually doing things.

My approach:

```text
Learn something
      ↓
Write it down
      ↓
Try it myself
      ↓
Something breaks
      ↓
Figure out why
      ↓
Fix it
      ↓
Write down what I learned
```

A lot of the practical stuff will be done in my HomeLab.
