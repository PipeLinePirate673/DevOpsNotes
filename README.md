# DevOpsNotes

My personal notes from learning DevOps.

I'm using this repository to document what I learn along the way — commands, concepts, configurations, problems I run into and solutions that I want to remember.

I don't want to just copy commands and forget them. I want to understand what I'm doing, practice it myself and have a place I can come back to later.

Learning
--------

I want to learn mostly by actually doing things.

My approach is pretty simple:

```text
Learn something
      ↓
Write it down
      ↓
Try it myself
      ↓
Something breaks
      ↓
Figure out why
      ↓
Fix it
      ↓
Write down what I learned
      ↓
Try it again
```

A lot of the practical stuff will be done in my HomeLab.

## Progress

This is going to be a long-term project.

I don't want to consider something "completed" just because I read about it once.

For me, understanding a topic means being able to:

* explain the basics
* use it myself
* solve simple problems
* troubleshoot when something goes wrong
* use it in a practical project

I'll add and update the notes as I go.
